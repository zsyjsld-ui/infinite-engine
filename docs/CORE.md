# 模块边界

World由单一所有者修改，实体使用槽号/代际，位置与高频状态按连续列保存。默认50ms整数tick和1/16世界像素；网络显式编码，不发送Rust内存布局。

core提供正方格/交错行地图、整数碰撞、可恢复预算寻路、缓存/共享目标搜索、移动、生命/战斗、属性/效果、AI、生命周期、空间查询、同步和总工作预算。业务选择执行阶段与规则，不将库中存在的模块视为参考服务已执行的模块。

MovementRuntime是直接权威入口：方向向量受限并保留余数，点击规划与移动共用地图，处理序号、纪元、租约、暂停和停止。网络输入不扩大时间或规划份额。

参考服务有64连接准入上限，每连接32条输入队列、每tick输入工作上限、2包可见交接队列和发送/ACK期限。自身和可见流分别确认；断线回收实体，重连换纪元/代际。进程内保留合成角色位置，重启持久恢复尚未接入。

每tick共享空间捕获，接收者增量准备。字节预算是模拟侧准入，不是网卡限速。应用应组合移动、战斗、效果、同步和保存的顺序，不维护第二份权威世界。

infinite-store/examples/server是多系统合成集成示例，不是独立移动参考服务的默认配置。
