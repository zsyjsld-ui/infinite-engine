# NM02 移动参考协议

所有整数小端。WebSocket二进制消息承载一个应用包，NM02包以4字节魔数、1字节kind、3字节零保留字段开始。长度/保留位/身份不符拒绝。建议直接使用`infinite-protocol`编解码函数，不复制结构体内存。

|方向/kind|长度|内容|
|---|---:|---|
|客户端1 Hello|40|32字节合成token|
|客户端2 Input|40|epoch u64@8、seq u64@16、操作u8@24、x/y i32@28/32|
|客户端3 ACK|32|epoch/tick/intent u64@8/16/24|
|客户端4 Ping|16|本地发送微秒u64@8|
|服务端128 Welcome|72|epoch/actor/instance u64@8/16/24，tick毫秒u32@32，单位/像素u32@36，地图SHA256@40|
|服务端129 State|116＋路线|权威状态、序号、方向余数、目标/半径/租约及可选精确路线游标|
|服务端130 Pong|24|回显发送时间、服务端微秒|
|服务端131 Delta|变长|40字节头＋变化字掩码和值，无损恢复129|
|服务端132 VisibilityWelcome|24|可见流u64@8，自身实体槽号/代际u32@16/20|

Input操作：0停止、1方向、2目标、3租约心跳。停止/心跳的x/y必须为0；方向必须能表示为i16且平方范数不超过32767²。epoch/seq非零，客户端不能提供速度、模拟时间或路线游标。已接收、已处理、当前意图序号是不同字段。

State的phase：0空闲、1等待、2移动、3到达、4阻挡、5失败、6取消、7暂停。116字节头包含路线版本、采样时间及余数，具体字段布局与严格约束见`infinite-protocol/src/wire.rs`。路线最多1024点，恢复时必须验证地图和游标。

Delta头：epoch/baseTick/tick u64@8/16/24，完整包长度u32@32，4字节字数u16@36，掩码字节数u16@38。双方最多128帧历史，只引用实际发送并已ACK的基线。使用`StateHistory::expand`后仍需`decode_server`验证语义；成功应用后再commit和ACK，重连清空。

附近复制另用IS载荷与20字节IA ACK；使用`infinite_core::Replica`应用并回传其acknowledgement，流身份由132提供，自身实体不重复绘制。自身ACK不能替代可见流ACK。此移动服务未发送IC战斗事件流。

## 地图与合成账号

IMAP文件：32字节头＋逐格1位阻挡，低位优先；魔数IMAP、u16版本1@4、u16几何3@6、宽/高u32@8/12、列宽/行高u32@16/20、原点x/y i32@24/28。最多1048576格，行交错；实际几何合法性由`MapAsset::decode`验证。示例列宽768、行高192，即48×12世界像素。

合成账号每行：id、64个十六进制字符token、整数x、整数y、u16速度。启动时读取，不是正式账号数据库。服务只监听本机回环，Origin必须匹配配置；不要将参考认证流程直接暴露为生产登录。
